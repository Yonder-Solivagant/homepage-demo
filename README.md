# homepage-demo

《人工智能与数据分析》(MF70050.01) 作业 1 · 个人主页

- 仓库：https://github.com/Yonder-Solivagant/homepage-demo
- 网页：https://homepage-demo-jade-phi.vercel.app

单文件静态页 `index.html`，无构建步骤、无外部依赖（字体走系统字体栈，样式内联）。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署

部署在 Vercel（项目名 `homepage-demo`，Hobby）。改动推送后如需手动发布：

```
vercel deploy --prod
```

> 备注：`*.vercel.app` 域名在中国大陆网络下 DNS 被污染，直连打不开，需要走代理。
